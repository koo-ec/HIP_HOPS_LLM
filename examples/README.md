# Examples

Six runnable scripts. Each one runs against bundled data — no GPU, no API key, no
network — and each is executed by CI, so none of them can quietly go stale.

```bash
pip install -e ".[all]"
python examples/01_analyse_architecture.py
```

| | | |
|---|---|---|
| 1 | [`01_analyse_architecture.py`](01_analyse_architecture.py) | Structure alone: cut sets, single points of failure, the FMEA. Needs no data at all — run it the day you write the graph. |
| 2 | [`02_calibrate_and_quantify.py`](02_calibrate_and_quantify.py) | Measure under an operational profile; check the union-splitting rule is exact; see how the answer moves with the workload. |
| 3 | [`03_bayesian_network.py`](03_bayesian_network.py) | CPTs, exact inference cross-checked two ways, diagnosis, and a PNG that needs no Graphviz. |
| 4 | [`04_compare_architectures.py`](04_compare_architectures.py) | Three architectures side by side, and whether diversifying the models actually helps. |
| 5 | [`05_learned_cpts.py`](05_learned_cpts.py) | Fit an aggregator's table from data rather than assuming it is an AND gate. |
| 6 | [`06_your_own_langgraph.py`](06_your_own_langgraph.py) | A live compiled LangGraph, with a mermaid fallback so it always runs. |

## What each is meant to show

**1** — the structural findings are free and often the ones worth acting on
first. Every cut set in the ReAct architecture is order 1, and `eval()` in the
calculator tool is a catastrophic single point of failure.

**2** — `react_agent` fails on 5% of short questions and 61% of long ones. A
single pooled accuracy averages that away, and any deployment whose workload
differs from the benchmark's inherits a wrong number.

**3** — the exact network probability and the minimal cut upper bound bracket the
answer, and the gap between them is the cost of assuming cut sets are
independent when they share basic events.

**4** — diversifying *one* of two parallel agents changes nothing, because the
judge still shares a snapshot with the other. You have to diversify the judge too.

**5** — the real aggregator gate is neither AND nor OR: it fails 18% of the time
when *both* drafts are right, and it is asymmetric between its two inputs. No
deterministic gate can express either fact.

**6** — the whole pipeline against a graph you built, including what to pass so
that shared-snapshot detection works.
